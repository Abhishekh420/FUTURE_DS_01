# Business Sales Performance Analytics

## Project Objective

Analyze business sales data to identify revenue trends, top-selling products, category performance, and regional insights.

Sample Superstore Dataset

## Tool Used

## Business Recommendations

* Focus on high-performing product categories
* Improve performance in low-sales regions
* Monitor sales trends for better decision-making
